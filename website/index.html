tq-bridge

同一套 tqcenter API，跨机器调用通达信

在一台已登录的 Windows 通达信上运行网关，macOS / Linux / Windows 客户端只改包名即可取数、订阅行情与转发文件。

查看仓库 API 参考

一条链路，两端同构

业务脚本调用远程 SDK，网关在 Windows 上转成本机真实 tqcenter。

  1. 客户端 from tqcenter_remote import tq, tqconst — 任意平台
  2. 网关 HTTP /rpc · WebSocket /ws/sub · 可选 Bearer Token
  3. 通达信 TPythClient.dll → 已登录客户端本地取数

覆盖日常取数场景

远程 SDK 与官方 tqcenter 方法对齐，网关按白名单转发。

  • 行情与 K 线 快照、复权 K 线、除权因子、涨跌停与盘口量价
  • 标的与板块 股票列表、板块树、成分股、代码联想匹配
  • 财务与日历 财报、交易日历、IPO / 可转债 / 股本等扩展信息
  • 实时订阅 subscribe_hq 经 WebSocket 推送，回调留在客户端本机
  • 文件与展示 上传 send_file、下载转发、print_to_tdx 落盘到网关机
  • 交易（可选） 默认开放；生产建议 TQ_BRIDGE_ALLOW_TRADE=0 关闭下单撤单

改一个包名就能跑

Windows 网关常开后，任意平台脚本保持官方调用习惯。

Python · tqcenter_remote 
# from tqcenter import tq, tqconst
from tqcenter_remote import tq, tqconst

tq.initialize(__file__)
df = tq.get_market_data(
    stock_list=["688318.SH"],
    count=5,
    period="1d",
    dividend_type="front",
)
print(df)
tq.close()

1. Windows：登录通达信，执行 python -m tq_bridge

2. 客户端：设置 TQ_BRIDGE_URL / Token，或放置 tq_bridge.json

3. 运行策略：方法名与参数与官方 tqcenter 一致

API 参考

业务侧优先使用 Python SDK；需要自建客户端时再对接网关 HTTP / WebSocket。

Python SDK · tqcenter_remote.tq

签名与官方 tqcenter.tq 对齐。完整冒烟见仓库 tdxdata_test_remote.py。

生命周期

initialize(path="", dll_path="")
读取网关配置并检查 /health；签名兼容官方，不在本机加载 DLL
close()
断开 WebSocket，并通知网关注销当前 client_id

行情 / K 线

get_market_data(...)
历史 K 线；常用 period：1m / 5m / 1d / 1w；复权 none / front / back
get_market_snapshot(...)
实时或缓存快照
get_stock_info(...) · get_divid_factors(...)
标的基础信息、除权因子
refresh_cache(...) · refresh_kline(...)
强制刷新缓存 / K 线
get_pricevol(...) · get_zdt_data(...) · get_exday_data(...)
量价、涨跌停、扩展日频数据

板块 / 列表 / 日历

get_sector_list(list_type=0)
板块列表
get_stock_list_in_sector(...) · get_user_sector()
板块成分、用户板块
get_stock_list(...) · get_match_stkinfo(...)
全市场列表、关键词匹配
get_trading_calendar(...) · get_trading_dates(...)
交易日历与交易日序列

财务 / 扩展信息

get_financial_data(...) · get_financial_data_by_date(...)
财务报表及按日切片
get_gpjy_value* · get_bkjy_value* · get_scjy_value*
股票 / 板块 / 市场经营类指标（含 by_date 变体）
get_ipo_info · get_kzz_info · get_gb_info* · get_more_info
IPO、可转债、股本等扩展字段

订阅

subscribe_hq(stock_list, callback)
订阅推送；callback 仅在客户端执行，经 /ws/sub 收包
unsubscribe_hq(...) · get_subscribe_hq_stock_list()
取消订阅、查询当前订阅列表

文件 / 交易

send_file(path)
客户端本地文件先上传到网关临时目录，再交给通达信
print_to_tdx(...) · download_file(...)
结果落在 Windows 通达信目录；下载经网关转发
stock_account · order_stock · cancel_order_stock
交易类；网关可用 TQ_BRIDGE_ALLOW_TRADE=0 禁用后两项
订阅行情示例 
from tqcenter_remote import tq

tq.initialize(__file__)

def on_hq(data_str: str):
    print(data_str[:200])

tq.subscribe_hq(stock_list=["688318.SH"], callback=on_hq)
print(tq.get_subscribe_hq_stock_list())
# ...
tq.unsubscribe_hq(stock_list=["688318.SH"])
tq.close()

网关 HTTP / WebSocket

默认监听 0.0.0.0:18787。设置了 TQ_BRIDGE_TOKEN 时，HTTP 需 Authorization: Bearer <token>。

GET /health
健康检查；返回 ok / initialized / allow_trade / 方法白名单
POST /rpc
通用 RPC：{"method","args","kwargs","client_id?"} → {"ok","result","error"}
POST /files/upload
上传文件：name + content_b64 → Windows 本地路径
GET /files/download?path=
按网关本机路径下载，返回 content_b64
WS /ws/sub?token=&client_id=
行情推送通道；与 subscribe_hq 的 client_id 对应
POST /rpc 
curl -s http://127.0.0.1:18787/rpc \
  -H "Authorization: Bearer your_secret" \
  -H "Content-Type: application/json" \
  -d '{
    "method": "get_market_snapshot",
    "args": [],
    "kwargs": {"stock_code": "688318.SH", "field_list": []}
  }'

配置项

TQ_BRIDGE_URL
客户端：网关根地址，如 http://192.168.1.100:18787
TQ_BRIDGE_TOKEN
两端共享的 Bearer Token；也可写在 tq_bridge.json
TQ_BRIDGE_HOST / TQ_BRIDGE_PORT
网关监听，默认 0.0.0.0:18787
TQ_BRIDGE_ALLOW_TRADE
设为 0 禁用 order_stock / cancel_order_stock
TQ_BRIDGE_INIT_PATH
网关调用本机 tq.initialize 时使用的路径
